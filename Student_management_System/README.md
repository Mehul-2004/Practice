# Student Management System

## Overview

A console-based Student Management System built using Python and MySQL.

## Features

* Add Student
* View Students
* Update Student Marks
* Delete Student
* Search Student
* Input Validation
* Exception Handling

## Technologies Used

* MySQL
* mysql-connector-python
* Git & GitHub
